# Expense Tracker

A small expense tracker for my college project, built with plain HTML, CSS and JavaScript.

## What it does

- Add, edit and delete expenses (title, amount, category, date)
- Checks the form before saving
- Filter by category or month, sort by date or amount
- Shows the total spent and the total for each category
- Light and dark mode, and it remembers your choice
- Saves everything in localStorage, so it stays after a refresh

## How to run

Open `index.html` in a browser. There is nothing to install.

## Files

- `index.html` - the page
- `style.css` - the styling
- `script.js` - all the logic

## Notes

- The totals change when you use the filters.
- Firefox on desktop has no month picker, so type the month like `2026-10`.
- Data is stored in your browser only. Clearing site data deletes it.
